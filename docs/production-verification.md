## 回归验证补充了攻击、集结点和建筑部件

| 原因 | 修复后的行为 |
| --- | --- |
| 战机没有所属机场和弹药状态 | 战机返航着陆，装弹后继续攻击 |
| 单位避让把四架飞机互相推开 | 四个停机位保持原版坐标 |
| 所有武器显示同一种弹道 | 导弹、投弹、鱼雷、光束和近战采用各自表现 |
| 驱逐舰错误地防空 | 驱逐舰使用舰炮和反潜出击效果 |
| 谭雅用远程手枪拆建筑 | 谭雅靠近后使用 C4，并可游泳 |
| 超时空军团兵普通步行 | 军团兵传送后等待恢复 |
| 夜鹰在空中卸载步兵 | 夜鹰先着陆，再卸载步兵 |
| 生产建筑没有集结点 | 建筑保存集结点，并显示旗帜和连接线 |
| 多座工厂始终由首座出兵 | 玩家可以双击建筑选择主工厂 |
| 雷达只处理左键 | 雷达右键也移动视图 |
| 满额物品从列表消失 | 超级武器和谭雅保留禁用按钮 |
| 转换器漏读 SuperAnim | 超时空球体等静止部件完整显示 |
| 转换器漏读 TurretAnim | 巨炮、爱国者、哨戒炮和防空炮显示转向炮塔 |
| 巨炮用错误的美术配置名 | 转换器使用 GTGCAN 配置和两格地基 |
